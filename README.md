# packproc

Pack encode/decode helpers for proc payloads in pipelines.

**Site:** https://theworker02.github.io/packproc/

## Install / run

```bash
git clone https://github.com/theworker02/packproc.git
cd packproc
node src/cli.js
node --test
```
